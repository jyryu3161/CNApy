# Contributing

Thank you for considering contributing to this fork of CNApy! This file contains instructions for contributing to this fork specifically.

## Where to contribute

This repository is a research-oriented fork of the original [cnapy-org/CNApy](https://github.com/cnapy-org/CNApy), maintained at [jyryu3161/CNApy](https://github.com/jyryu3161/CNApy).

- **For fork-specific features** (GECKO enzyme-constrained modeling, E-Flux2, Dynamic FBA, FSEOF/FVSEOF, Batch MOMA/ROOM, Gene Essentiality Analysis, Robustness Analysis, etc.) — contribute to this fork.
- **For core CNApy functionality** that exists in upstream — consider contributing to the [upstream cnapy-org/CNApy](https://github.com/cnapy-org/CNApy) repository so that the wider community benefits.

## How to make a contribution to this fork

* (optional) Open an [issue](https://github.com/jyryu3161/CNApy/issues/new) describing what you want to do.
* Fork the [jyryu3161/CNApy](https://github.com/jyryu3161/CNApy/) repository and create a branch for your changes.
* Submit a pull request to the `master` branch of this fork with your changes.
* Respond to feedback on your pull request.
* If everything is fine your pull request is merged.
